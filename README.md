# 우리 은하 3D 관찰

첨부된 3D 관찰 예시를 바탕으로 만든, 퀴즈와 학습 단계가 없는 간단한 은하 관찰 자료입니다.

## 실행

루트의 index.html을 브라우저로 엽니다. 빌드·설치·인터넷 연결 없이 실행합니다. index.html, style.css, app.js, galaxy-model.js, vendor 폴더를 함께 보관하세요.

WebGL 지원 브라우저가 필요합니다. 태블릿 파일 앱의 HTML 미리보기에서는 스크립트가 실행되지 않을 수 있으므로 실제 브라우저를 사용하거나 파일을 정적 웹 서버에 올려 접속하세요.

## 조작

- 한 손가락 또는 마우스 드래그: 시점 회전
- 두 손가락 모으기·벌리기, 마우스 휠, +/− 버튼: 확대·축소
- 전체 모습 / 위에서 보기 / 옆에서 보기 / 태양계 위치: 관찰 시점 이동
- 자동 회전 시작·멈춤: 은하 주위를 도는 관찰 시점 회전 (실제 공전 재현 아님)

길쭉한 중심 막대, 막대 양끝에서 이어지는 주 나선팔과 분지, 얇은 원반, 부푼 중심부를 별 입자로 표현했습니다. 태양계 표식은 모형에서 중심 반지름의 약 52% 위치에 있습니다. 별 수·색·밝기·나선팔 세부 배치와 태양계 각도는 학습을 위한 단순화이며 정밀 관측 지도가 아닙니다. 표식의 크기는 실제 천체 크기와 무관합니다. 블랙홀 요소는 포함하지 않습니다.

관찰 화면은 학습 기록을 저장하거나 외부로 전송하지 않습니다.

## 라이브러리와 검사

Three.js r128과 같은 버전의 OrbitControls를 vendor에 포함했습니다. 라이선스: vendor/THREE-LICENSE.txt (MIT).

node --check app.js
node --check galaxy-model.js
node smoke-test.cjs

테스트는 은하 구조·좌표·의존 파일을 확인합니다. 실제 브라우저 렌더링과 태블릿 터치 검증은 별도로 필요합니다.

## 은하 표현 개선

2025년 ESA/Gaia 재구성 자료의 넓고 덜 뚜렷한 나선 구조를 참고해, 연속적인 별빛 원반에 네 개의 불규칙한 나선 밀도 영역을 겹치도록 변경했습니다. 관측 데이터를 직접 맞춘 모형은 아닙니다. 중심 막대와 중심부는 경계가 부드러운 분포이며, 먼지 구조는 끊어진 명암으로 표현합니다. 총 입자는 74,100개입니다.

참고: https://www.esa.int/ESA_Multimedia/Videos/2025/01/The_best_Milky_Way_animation_by_Gaia
3D 표현 참고: https://gaiasky.space/
외부 자료의 코드나 이미지 자산을 복사하지 않고 기존 로컬 모형을 수정했습니다.

preview-model.cjs가 생성하는 model-preview.png는 같은 좌표와 표면 함수를 사용하는 위 모습 진단 이미지입니다. WebGL 화면 캡처가 아니며 실제 브라우저의 합성 결과와는 다릅니다.

## 태양을 원점으로 관찰

‘태양에서 바라보기’는 카메라 위치를 태양에 고정하고 시선만 돌리는 내부 관찰 모드입니다. 원점은 태양이며 좌우 0°는 원반을 따라 은하 중심을 향하는 방향, 상하 0°는 원반에 평행한 방향입니다. 정확한 천문학적 은하좌표계나 지구에서 본 별자리 하늘을 재현하지 않습니다.

한 손가락 드래그 또는 좌우·상하 슬라이더를 사용하세요. 중심 방향·반대 방향·원반 위쪽 바로가기를 제공합니다. 두 손가락, 휠, ＋/−는 시야각만 조절하며 관측 위치는 이동하지 않습니다. 다른 관찰 버튼을 누르면 외부 시점으로 돌아갑니다. 외부 관찰용 평면 별빛 질감은 내부 모드에서 숨겨, 원반이 벽처럼 보이는 현상을 피합니다.

node sun-view-test.cjs는 회전·확대 중 태양 원점 고정과 시선 계산을 검사합니다. 실제 태블릿 제스처 검증은 별도로 필요합니다.
